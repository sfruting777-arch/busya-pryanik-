# 🐾 Буся против Пряника — закладки / ИДЕИ

## Утверждённый план Meshy для первого уровня (11 ноября 2026)

**Статус:** сохранено для будущей работы; выполнять **строго по порядку, с шага 1 до шага 5**, когда пользователь напомнит. Не начинать генерации без нового запроса.

**Ресурс:** подписка Meshy, на момент записи осталось около **1145 кредитов**.

### Пять шагов
1. **Фонтан** — красивая центральная модель для садового лабиринта, с возможностью программной анимации воды.
2. **Садовый фонарь** — одна оптимизированная 3D-модель для многократного размещения по карте.
3. **Скамейка** — уютная модель для центральной площадки возле фонтана.
4. **Клумбы** — два варианта, круглая и вытянутая/угловая, для украшения сада.
5. **Рама/стенд для скрытой фотографии** — нарядная конструкция с полностью непрозрачным занавесом. Семейное изображение должно быть скрыто до финала.

**Стилистика:** уютный королевский сад с умеренной сказочностью; стилизованная качественная мобильная 3D-графика, в духе утверждённого референса с симметричным геометрическим лабиринтом и широкими дорожками. Избегать чрезмерно тяжёлых GLB. Использовать одну модель многократно, где возможно.

**Что делаем без кредитов Meshy:** геометрию лабиринта, дорожки, основные изгороди, базовые деревья и растительность, столкновения, камеру, игровую логику и финальный триггер.

**Герои уже утверждены:** Буся 1.0 (оригинальный характер и стиль), Пряник 2.0 (финальная игровая анимация v26). Не менять без нового согласования.

**Смысл финала:** после последнего Monge прекращается погоня, собаки встречаются у фонтана, падает занавес и впервые показывается семейная фотография. Появляется утверждённая надпись:
> «Даже если весь мир превратится в огромный лабиринт, главное — всегда находить дорогу друг к другу».
